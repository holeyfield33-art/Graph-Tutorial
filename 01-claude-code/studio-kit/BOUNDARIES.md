# Boundaries and evidence limits

This kit packages existing Software Research Studio agent-facing guidance (status 2026-11-01) for reuse.

- **003R automatic selector**: NO-GO. Do not market or use this kit as a proven autonomous engineering intelligence system.
- **Performance claims**: None. Qualitative examples of improved awareness exist; independent measurement is future work.
- **Kernel**: Not required. The Studio kernel remains optional supporting tooling and is unchanged by this package.
- **Source**: Derived from `PRODUCT_INTENT.md`, `AGENTS.md`, `AGENT_INTAKE.md`, and relevant sections of `REPOSITORY_KNOWLEDGE_LAYOUT.md` in the Software Research Studio repository. No new frameworks invented.
- **Scope**: Contextual engineering guidance for coding agents. Not a runtime, dashboard, subscription, or full SDLC bureaucracy.

Honest use: equip an agent so it notices more of the requirements and checks that matter for the actual product being built.
