## Start with the bonus

1. Read `bonus/START_HERE.md` and `bonus/DOC_MAP.md`.
2. Use `bonus/FIRST_SESSION_PLAYBOOK.md` to select a task based on the project's actual condition.
3. Load `AGENTS.md` using your agent's **current, project-specific** instructions mechanism. Do not overwrite existing rules. See https://github.com/holeyfield33-art/studio-engineering-kit/blob/main/docs/PLATFORM_SETUP.md for public setup guidance.
4. Ask the agent to inspect before proposing docs. Review changes and actual tests yourself; a summarized instruction is only a loading check.
